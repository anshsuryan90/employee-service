Employee Service

A Spring Boot RESTful web service for employee management, supporting employee retrieval, JSON data upload, and unit testing using JUnit.

Features:
- Retrieve employee data using HTTP GET requests
- Add employees using HTTP POST requests
- JSON request and response handling
- Unit testing with JUnit
- Built using Spring Boot and Gradle

API Endpoints:
GET /employees
Returns the list of all employees.

POST /employees
Adds a new employee.

Technologies Used:
- Java
- Spring Boot
- Gradle
- JUnit
